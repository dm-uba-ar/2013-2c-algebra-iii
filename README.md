### Correlatividades

De acuerdo con el régimen de correlatividades vigente, para poder cursar esta materia es necesario tener aprobados los trabajos prácticos de Álgebra II y el final de Álgebra Lineal.

### Régimen de aprobación

Se deben aprobar dos exámenes parciales. Habrá dos fechas de recuperación al finalizar el cuatrimestre, una para cada examen. Para poder ser incluído en las actas de trabajos prácticos, es necesario haberse inscripto mediante el [sistema de inscripciones de la facultad](http://inscripciones.exactas.uba.ar/exactas/).
